# Metrics: reusable financial measures

A metric gives a financial measure a stable identity that can be reused by Pages, agents, Lil Piggy, and other metrics.

A metric is more than the latest number.

## Definition versus values

| Part | Answers |
| --- | --- |
| **Metric definition** | What is this measure, how is it calculated, how is it formatted, and what does it depend on? |
| **Metric value or series** | What was the value for this period or point in time, under this scenario, and where did it come from? |

A definition can include a name, key, description, value type, unit, formula, dependencies, source references, presentation metadata, input flag, and active/archive state. Values carry periods or timestamps plus provenance.

## Four building blocks

### System references

Read-only values derived from connected books or a plan, such as Revenue, COGS, Gross profit, OpEx, or Ending cash. Duplicate a system reference when you need an operator-owned tracked definition.

### Saved metrics

Reusable measures owned by the client. A saved metric can depend on system references, inputs, assumptions, or other saved metrics.

### Reusable inputs

Directly entered scalar values saved through the metric system. An input has no formula and can be referenced by several metrics—for example, a target margin or annual contract value.

### Forecast assumptions

Planning primitives that belong to a model or scenario. They are distinct from reusable inputs and from durable business Context.

## Time and grain

Every metric should make its time behavior obvious:

- **Periodized flow** — revenue for March
- **Point in time** — cash balance as of March 31
- **Rolling window** — trailing-three-month gross margin
- **Scenario value** — forecast ending cash for a selected plan

The source grain determines what can be grouped or filtered safely. Do not present a monthly statement snapshot as if it were transaction-level evidence.

## Provenance and missing data

A trustworthy metric exposes enough information to understand its source period, dependencies, and availability. Unavailable is not zero. Ambiguous or missing references should fail closed.

## Shared meaning, local presentation

The metric owns meaning and calculation. A Page block owns display choices such as date window, comparison, chart style, order, or visible dimensions. This lets one metric appear in several views without creating conflicting definitions.
