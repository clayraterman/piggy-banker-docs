Pages are where your financial data becomes a story. Each page is a free-form, Notion-style canvas that you populate with blocks — metric widgets, charts, tables, and written narrative — arranged exactly how you want them. There are no rigid templates forcing you into a fixed layout: you decide which metrics matter for each client and how to present them. A page can be a simple burn-rate scorecard, a full board-ready P&L report, or a live operating dashboard your client checks every morning.

## What Is a Page?

A **page** in Piggy Banker is a canvas made up of **blocks** stacked top to bottom. You add blocks, rearrange them freely, and connect each block to the live metrics and data powering your client portal.

The available block types are:

<CardGroup cols={2}>
  <Card title="Metric Widgets" icon="gauge">
    Display a single live metric value — a number, a percentage, or a currency amount — with optional trend indicators and comparison to a prior period or target.
  </Card>
  <Card title="Charts" icon="chart-bar">
    Visualize one or more metrics over time with line charts, bar charts, and custom visuals. Charts update automatically as the underlying metric data refreshes.
  </Card>
  <Card title="Tables" icon="table">
    Show multiple metrics in a structured grid — useful for P&L statements, budget vs. actuals comparisons, and multi-department breakdowns. Rows and columns map directly to live metric values.
  </Card>
  <Card title="Text Blocks" icon="text">
    Add narrative context, section headings, or explanatory notes alongside your numbers. Use text blocks to annotate what a metric means for this specific client.
  </Card>
</CardGroup>

Pages can be nested. A top-level **Board Reporting** page can contain subpages for each board meeting, all sharing the same underlying metrics without duplicating data.

## Building a Page

Building a page in Piggy Banker is an additive process — you start with a blank canvas and layer in blocks as you go. You can build manually or ask Piggy to scaffold a page for you.

<Steps>
  <Step title="Create a new page">
    In the client portal sidebar, click **+ New Page**. Give the page a name that reflects its purpose — for example, *Monthly P&L*, *Cash Dashboard*, or *Board Deck – Q3*.
  </Step>
  <Step title="Add your first block">
    Click **+ Add Block** and choose the block type: metric widget, chart, table, or text. Each block type prompts you to select the metric or data source that powers it.
  </Step>
  <Step title="Connect metrics as data sources">
    For each block, select the metric you want to display. The block immediately pulls in live data from that metric. You can also ask Piggy in the chat panel to add a specific block: *"Add a chart showing Monthly Revenue for the last 12 months."*
  </Step>
  <Step title="Arrange and refine">
    Drag blocks to reorder them on the canvas. Resize blocks to emphasize the most important numbers. Add text blocks between data blocks to provide narrative context.
  </Step>
</Steps>

<Note>
When you ask Piggy to move or reorder an existing block on a page, it preserves the block's configuration and data connection. Always ask Piggy to reorder rather than delete and recreate a block to avoid losing your settings.
</Note>

## Using Templates

Starting from a blank page is powerful but time-consuming when you need the same layout across multiple clients. Piggy Banker's **Playbooks** feature lets you save any page layout as a reusable template.

To apply a template when building a page:

<Steps>
  <Step title="Choose 'Start from Template' at page creation">
    Instead of opening a blank canvas, select **Start from Template** and browse your saved Playbook templates.
  </Step>
  <Step title="Select a template">
    Pick the template that matches the report type — for example, *Monthly Close Report* or *Investor Dashboard*. Piggy Banker clones the layout into the new page.
  </Step>
  <Step title="Connect metrics to the new client's data">
    Template blocks carry the layout but need to be connected to this client's metrics. Update each block's data source to point to the correct metric for this portal.
  </Step>
</Steps>

For a deep dive on creating and managing templates, see [Playbooks and Templates](/concepts/playbooks).

## Sharing Pages

Share a live, read-only view of any page with a client, investor, or stakeholder — no Piggy Banker account required on their end.

To share a page:

1. Open the page you want to share.
2. Click **Share** in the top-right corner.
3. Copy the generated link and send it to the recipient.

The recipient sees a read-only snapshot of the page that updates in real time as your metrics refresh. They cannot edit the page, change any data, or access any other section of the client portal.
