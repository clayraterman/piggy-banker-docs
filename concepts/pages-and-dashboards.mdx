A Page combines saved Metrics and written context into a finance view you can revisit, share, and use with agents. Pages is available in each company or managed-client workspace.

## Create and edit

Use **New page** in the sidebar. Give the Page a useful title, then add text or choose a block with the add control. The block picker includes finance tables, charts, statements, KPI views, planning views, and custom tools.

Choose only the blocks needed for one decision. Each block still needs valid inputs; selecting a statement block does not create missing accounting data.

Changes autosave. Check **Saved** before closing the browser. If a save fails, keep the Page open and use **Retry** after the cause is resolved. See [Troubleshooting](/reference/troubleshooting#page-changes-are-not-saved).

## Bind a metric instead of pasting a number

A metric-backed block reads a saved definition and series. Pasted narrative is text and does not update when the source changes.

| Shared metric | Page block |
| --- | --- |
| Definition, formula, and source | Selected metric |
| Format and rollup | Date window and comparison |
| Period values and scenario assumptions | Chart, table, and layout choices |

Open **Metrics** from the Page to manage shared measures, source data, and dimensions. A correction to a shared metric can affect every Page or agent that uses it. Review dependent views after changing its definition.

## Keep the period visible

Confirm the Page's date window and scenario. A monthly flow, ending balance, and forecast assumption are different measures even when they share a label. Missing sources remain missing; a blank value should not be explained as zero.

After a source refresh, follow any reload prompt and recheck the value. A written explanation of last month's results does not become current simply because a chart refreshes.

## Pages and agents

Authorized agents can read saved Metrics and Pages alongside Context. A Page marked as a playbook provides written guidance for agents. Available tools and data depend on the agent configuration and workspace permissions.

A successful read or generated report does not itself publish the Page or send it anywhere. Review the output and destination separately.

## Reuse and share

- Save reusable structure with **Share** → **Export** → **Save…**, or **Save as template…**.
- Open **Templates & playbooks** to apply reusable content inside another authorized client.
- Use **Share** for workspace viewing, **Publish** for a secret link, and **Export PDF** for a snapshot.

Before sharing, read [Sharing and access](/reference/sharing-and-access). Before relying on the numbers, follow [Verify your first workflow](/guides/verify-your-first-workflow).
