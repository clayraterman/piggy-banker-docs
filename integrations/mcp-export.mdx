Piggy Banker can export your financial data in MCP (Model Context Protocol) and WebMCP formats, letting external AI agents like Claude or GPT read and interact with your live financial models. Instead of copying numbers into another tool, you point your AI agent at Piggy Banker and it queries your data directly — always getting the latest figures from the source.

## What Is MCP?

MCP (Model Context Protocol) is an open standard that lets AI tools connect to external data sources in a structured, authorized way. Think of it as a secure API that AI agents know how to speak natively.

When you enable MCP export, Piggy Banker acts as an MCP server. Any MCP-compatible AI client — Claude Code, a custom agent, an AI-powered internal tool — can connect to your Piggy Banker workspace and query your financial data using the same underlying tools that power Piggy itself.

You stay in control: access requires authentication, and connections are read-only by default.

<Note>
  Each MCP session is scoped to a single client portal. External agents must specify which client they want to query. If your account has access to multiple workspaces, the agent must pass the correct workspace ID on each call.
</Note>

## Who This Is For

MCP export is built for developers and power users who want to bring Piggy Banker data into an external AI environment — without manual exports or copy-pasting.

Use MCP export if you want to:

- Query your financial metrics inside **Claude Code** from your terminal
- Build a **custom AI agent** that reads live burn rate, runway, or revenue figures from Piggy Banker
- Connect Piggy Banker data to an **AI-powered internal tool** your team already uses
- Automate financial analysis workflows that combine Piggy Banker data with other sources

If you just want to ask questions about your financials inside Piggy Banker, use Piggy's built-in chat — you don't need MCP for that.

## Connecting with Claude Code

<Steps>
  <Step title="Find your MCP endpoint URL">
    Open your Piggy Banker settings and navigate to **Integrations → MCP**. Copy your MCP endpoint URL — it's unique to your workspace.
  </Step>
  <Step title="Add the MCP server in your terminal">
    Run the following command, replacing `<YOUR_MCP_URL>` with the endpoint URL you copied:

    ```bash
    claude mcp add --transport http piggybanker <YOUR_MCP_URL>
    ```
  </Step>
  <Step title="Start Claude">
    Launch Claude Code from your terminal:

    ```bash
    claude
    ```
  </Step>
  <Step title="Open the MCP menu">
    Type `/mcp` inside Claude and look for `piggybanker` in the list of connected servers.
  </Step>
  <Step title="Authenticate">
    Select `piggybanker` and choose **Authenticate**. A browser window opens — make sure you're logged into your Piggy Banker account before approving the connection.
  </Step>
  <Step title="Verify the connection">
    Once authenticated, type a test query such as *"What is the current cash runway for Acme Corp?"* to confirm the connection is working and returning live data.
  </Step>
</Steps>

<Warning>
  MCP access is read-only by default. Granting write access allows external agents to update metrics and pages directly inside your Piggy Banker workspace. Only enable write access for agents and workflows you fully trust, and review any changes in your workspace after an external agent session.
</Warning>

## Connecting with Other MCP Clients

Any MCP-compatible client can connect to Piggy Banker — you're not limited to Claude Code. The setup process is the same in principle:

1. Retrieve your MCP endpoint URL from **Integrations → MCP** in your Piggy Banker settings.
2. Add the endpoint as a remote MCP server in your client's configuration.
3. Authenticate using your Piggy Banker account when prompted.

If your client supports custom server names, name it `piggybanker` to keep things consistent. If you run into issues, ask Piggy to walk you through the connection setup for your specific client.

## What External Agents Can Access

Once connected, an external agent can query the following from your Piggy Banker workspace:

- **Live metrics** — current values for any metric in your financial model (revenue, burn rate, cash runway, headcount, and more)
- **Context facts** — key facts and assumptions your model is built on
- **Page data** — the content of individual pages in your client portal
- **Metric history** — historical values across accounting periods

All access is **read-only by default**. An external agent cannot modify your model, update a metric, or change a page unless you explicitly grant write access in your Piggy Banker settings.

### Example: Querying metrics via MCP

```json
{
  "tool": "get_metrics",
  "params": {
    "client_id": "acme-corp",
    "metric_names": ["Monthly Revenue", "Burn Rate", "Cash Runway"]
  }
}
```

The agent returns current values for each metric directly from your live Piggy Banker model — no export step required.

## WebMCP for Web-Based Agents

**WebMCP** is a browser-based variant of MCP that exposes the same Piggy Banker data to web-hosted AI tools — no terminal setup required.

Use WebMCP when you want to connect Piggy Banker to a web AI tool that doesn't support CLI-based MCP configuration. The data available is identical to the standard MCP endpoint: live metrics, context, page data, and metric history.

To enable WebMCP, go to **Integrations → MCP** in your Piggy Banker settings and follow the WebMCP setup instructions for your specific web-based client.
