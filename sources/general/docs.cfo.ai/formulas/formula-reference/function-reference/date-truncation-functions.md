# Source: https://docs.cfo.ai/formulas/formula-reference/function-reference/date-truncation-functions

Date-truncation functions return the start of the period that contains a date.

## 

[​](https://docs.cfo.ai/formulas/formula-reference/function-reference/date-truncation-functions#startofday)

startofday

```
startofday(Date.Day)
```

Returns the start of the day.

## 

[​](https://docs.cfo.ai/formulas/formula-reference/function-reference/date-truncation-functions#startofweek)

startofweek

```
startofweek(Date.Week)
```

Returns the Monday at the start of the week.

## 

[​](https://docs.cfo.ai/formulas/formula-reference/function-reference/date-truncation-functions#startofmonth)

startofmonth

```
startofmonth(Date.Month)
```

Returns the first day of the month.

## 

[​](https://docs.cfo.ai/formulas/formula-reference/function-reference/date-truncation-functions#startofquarter)

startofquarter

```
startofquarter(Date.Month)
```

Returns the first day of the calendar quarter.

## 

[​](https://docs.cfo.ai/formulas/formula-reference/function-reference/date-truncation-functions#startofhalf)

startofhalf

```
startofhalf(Date.Month)
```

Returns January 1 or July 1 for the half-year containing the date.

## 

[​](https://docs.cfo.ai/formulas/formula-reference/function-reference/date-truncation-functions#startofyear)

startofyear

```
startofyear(Date.Month)
```

Returns January 1 of the year. These functions are useful when source dates must be aligned with a model period.
