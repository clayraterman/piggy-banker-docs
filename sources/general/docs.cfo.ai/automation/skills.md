# Source: https://docs.cfo.ai/automation/skills

A **Skill** is a saved process that tells Ari how to handle a recurring situation: what steps to take, what conventions to follow, and when to activate at all. Once saved, Ari activates a Skill on its own when a request matches its trigger condition — you don’t need to reference it by name.

## 

[​](https://docs.cfo.ai/automation/skills#built-in-and-saved-skills)

Built-in and saved Skills

cfo.ai ships with built-in Skills covering common workflows. Your workspace can also hold its own saved Skills, written for how your team specifically works. Ask Ari to list what’s available, including a search by name, to see both together.

## 

[​](https://docs.cfo.ai/automation/skills#create-a-skill)

Create a Skill

Ask Ari to save a new Skill and give it:

- **A name** — lowercase letters, digits, and hyphens, like `board-report`.
- **A trigger condition** — phrased as when it should activate, for example “Use when the user asks for a board or investor report.”
- **Instructions** — the full workflow: the steps, structure, and conventions Ari should follow once the Skill activates.

A good trigger condition is specific enough that Ari doesn’t activate the Skill for unrelated requests, but general enough to catch the different ways someone might phrase the same ask.

## 

[​](https://docs.cfo.ai/automation/skills#update-or-remove-a-skill)

Update or remove a Skill

Ask Ari to update a saved Skill’s description or instructions, or to delete one you no longer need. Built-in Skills can’t be edited or deleted — if a built-in Skill needs to work differently for your workspace, ask Ari to save a new one with a different name instead.
