# Source: https://docs.cfo.ai/dashboards/pages-and-blocks

A **Page** in cfo.ai is where your Model becomes readable: a dashboard made up of blocks arranged top to bottom. Pages can nest under one another, so you can organize, for example, a top-level “Board Reporting” Page with subpages for each meeting.

## 

[​](https://docs.cfo.ai/dashboards/pages-and-blocks#block-types)

Block types

- **Table Block** — a live grid built from your Variables and Dimensions. See [Build and format a Table Block](https://docs.cfo.ai/dashboards/build-and-format-tables).
- **Text block** — unstructured prose: narrative, context, or notes beside your numbers.
- **Chart or custom visual** — a visual representation built from live Model data. Use it when a Table Block’s grid is not the right shape, such as for a trend chart or a scorecard.

## 

[​](https://docs.cfo.ai/dashboards/pages-and-blocks#organize-a-page)

Organize a Page

Ask Ari to:

- Create a new Page, at the top level or nested under an existing one.
- Rename or move a Page, including reparenting it under a different Page.
- Create, reorder, or remove blocks on a Page.
- Move a block from one Page to another without losing its settings.

Because reordering an existing block preserves its configuration and ID, ask Ari to reorder a block rather than deleting and recreating it.

## 

[​](https://docs.cfo.ai/dashboards/pages-and-blocks#delete-a-page)

Delete a Page

Deleting a Page removes its blocks. If the Page has subpages, they move up to sit beside it rather than being deleted — only the Page you asked to remove and its own blocks are gone.
