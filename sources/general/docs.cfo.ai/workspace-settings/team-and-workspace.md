# Source: https://docs.cfo.ai/workspace-settings/team-and-workspace

Your workspace has a few settings that apply model-wide, rather than to any single Variable or Table Block. Ask Ari to change most of these directly.

## 

[​](https://docs.cfo.ai/workspace-settings/team-and-workspace#rename-the-workspace)

Rename the workspace

Ask Ari to rename your workspace. Renaming regenerates the workspace’s URL slug, so any link built from the old slug changes along with it.

## 

[​](https://docs.cfo.ai/workspace-settings/team-and-workspace#time-defaults)

Time defaults

Ask Ari to set the model’s default time settings:

- **Granularity** — the default roll-up grain for new tables, usually month.
- **Range** — the default start and end date a new table shows.

These are defaults for new Table Blocks; an existing table’s own window (see [Build and format a Table Block](https://docs.cfo.ai/dashboards/build-and-format-tables)) isn’t affected until you change it directly.

## 

[​](https://docs.cfo.ai/workspace-settings/team-and-workspace#last-close)

Last close

**Last close** is the date your Model computes Actuals against — everything at or before it is Actuals, and everything after is Forecast. Ask Ari to set it after each period closes in your books. Several other workflows, like [building a Headcount page](https://docs.cfo.ai/headcount/build-a-headcount-page), depend on Last close being set correctly first.

## 

[​](https://docs.cfo.ai/workspace-settings/team-and-workspace#team-directory-and-groups)

Team directory and groups

Ask Ari to look up who is in the workspace, including current team members, their roles, and pending invitations. Ari can also list user groups and the group details your access allows you to see.

## 

[​](https://docs.cfo.ai/workspace-settings/team-and-workspace#invite-or-remove-workspace-administrators)

Invite or remove workspace administrators

When you have the required access, Ari can invite someone as a workspace administrator, promote an existing teammate to administrator, or remove a person from the workspace. An administrator has broad workspace access. If your goal is to share a report without granting administrator access, use the Page’s **Share** control instead. Ari cannot invite someone with a lower role, create or edit groups, change Page-specific access, or create a share link on your behalf.
