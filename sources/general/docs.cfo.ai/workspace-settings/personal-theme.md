# Source: https://docs.cfo.ai/workspace-settings/personal-theme

Your personal cfo.ai theme is a small color recipe that changes how the interface looks for you specifically — it doesn’t affect what your teammates see.

## 

[​](https://docs.cfo.ai/workspace-settings/personal-theme#what-a-theme-controls)

What a theme controls

A theme is intentionally narrow. It sets:

- **Page and panel colors**, for both light and dark mode.
- **Text color** (“ink”), for both modes.
- **One interface accent** color, for both modes.

It does not touch the colors used for data series, or the built-in success and error colors on charts and Table Blocks — those stay consistent across every workspace so a red variance reads as a variance no matter who’s looking at it.

## 

[​](https://docs.cfo.ai/workspace-settings/personal-theme#set-a-theme)

Set a theme

Ask Ari to set a personal theme and describe the look you want, like “give me a deep teal accent with a near-black dark mode.” Ari reads your current recipe first (if you have one) and replaces it as a whole — a theme can’t be partially patched, so if you only want to change the accent, say so and Ari will carry the rest of your existing recipe forward. Give it a short, sentence-case label too, like “Teal dark,” so you can recognize it later in Settings.

## 

[​](https://docs.cfo.ai/workspace-settings/personal-theme#check-your-current-theme)

Check your current theme

Ask Ari what your personal theme is set to. If you’ve never set one, Ari will tell you there isn’t one yet, and the interface falls back to cfo.ai’s own default.
