# Create a metric from connected data

Create a metric when a financial measure should have one durable definition and be reused across models, Pages, agents, or Lil Piggy.

<Note>
  **UI transition:** Metric storage and evaluation exist today. The final management experience belongs inside Pages; current workspaces may expose the same primitives through compatibility reporting surfaces while Pages rolls out.
</Note>

<Steps>
  <Step title="Start with the decision">
    Write the question the metric should answer and who will use it. “Can we hire?” is more useful framing than “make a payroll chart.”
  </Step>
  <Step title="Choose the source and grain">
    Select a ready system reference, saved metric, reusable input, forecast assumption, or recorded value. Confirm the source period and whether the value is a flow, point-in-time balance, or scenario value.
  </Step>
  <Step title="Define dimensions and filters">
    Use only dimensions present at the source grain. State entity, department, class, customer, or other filters explicitly when the metric is not company-wide.
  </Step>
  <Step title="Name and describe the measure">
    Use a stable name, key, unit, and plain-language definition. Include exclusions or special accounting treatment in the description.
  </Step>
  <Step title="Build or record the value">
    Add a bounded formula, reference another metric, or save a reusable input. Keep forecast assumptions tied to their model or scenario.
  </Step>
  <Step title="Evaluate before saving">
    Review the resolved dependencies, sample period, null behavior, units, and source lineage. Correct unavailable or ambiguous references instead of substituting zero.
  </Step>
  <Step title="Choose presentation defaults">
    Set useful number or percentage formatting. Leave Page-specific choices—date range, comparison, chart type, order—to the Page block.
  </Step>
</Steps>

## Example: operating expense ratio

A sound definition identifies:

- numerator: Operating expense for the selected period,
- denominator: Revenue for the same period,
- entity and currency scope,
- behavior when Revenue is zero or unavailable,
- percentage formatting, and
- the connected statement periods used by each reference.

## Review checklist

- Does the name match the calculation?
- Are numerator and denominator on compatible periods and grains?
- Can an operator trace every dependency?
- Are inputs and assumptions visibly different from actuals?
- Does the definition remain useful outside one Page?
- Has a sample period been reconciled to the books?
