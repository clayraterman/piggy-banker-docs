# Piggy Banker documentation

Piggy Banker is a finance operating system for CFO teams and the businesses they support. It turns connected financial systems into **durable, auto-updating models** that people and agents can understand, reuse, and act on.

The product is designed to replace a familiar failure mode: a static spreadsheet with stale numbers, undocumented logic, and business context that lives only in one person's head.

## The core model

```text
Connection → source data with lineage → metric → Page block → agent workflow
                         ↑                 ↑
                     Context       inputs and assumptions
```

- **Connections** bring in accounting and balance data.
- **Source data** preserves what arrived, where it came from, and how fresh it is.
- **Context** records durable facts about how the business works.
- **Metrics** give financial measures stable names, definitions, formulas, and histories.
- **Pages** compose those metrics into decision-ready models and dashboards.
- **Agents** use the same grounded data to run repeatable workflows.
- **Lil Piggy** stays beside you as a private notepad and finance companion.

<Note>
  **Product availability:** These docs describe the intended product model and label material rollout boundaries. Pages and unified Page Templates/Playbooks are coming soon. External MCP/WebMCP access is not currently self-service.
</Note>

## Who Piggy Banker is for

### CFO firms

A firm workspace lets a CFO team manage multiple clients without mixing their data, access, Context, metrics, or agent activity. Shared templates and operating playbooks are designed to make the firm's best work reusable.

### Individual businesses

A solo operator uses the same client-level finance model without the multi-client operating layer. The pricing direction is a flat subscription plus optional additional usage; final solo packaging is still being completed.
